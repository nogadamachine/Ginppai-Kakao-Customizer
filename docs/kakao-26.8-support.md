# 카카오톡 26.8.0 대응

Ginppai-Kakao-Customizer 3.1.0은 26.7.3과 26.8.0을 지원합니다. 26.8.0 빌드 2026.9.14.1을 iPhone 13 Pro, iOS 26.1, LiveContainer 3.8.0에서 확인했습니다. Ginppai-Kakao-iPad는 기존 1.1.0을 그대로 사용합니다.

## 바뀐 부분

- 실행 파일의 버전과 UUID를 함께 검사해 버전에 맞는 함수 주소와 Swift 슬롯을 선택합니다. 다른 빌드는 초기화를 생략합니다.
- 메시지 기록, 삭제 원문 표시, 입력 중 표시 판단과 원본 사진 처리의 연결을 새 실행 파일에 맞췄습니다.
- 숏폼 버튼이 MainChip과 별도 컨테이너로 바뀐 구조를 처리합니다. 버튼과 빈 공간을 함께 숨기고 오픈채팅 선택을 유지합니다.
- 설정 하단에 실제 트윅 버전과 실제 카카오톡 버전을 표시합니다.
- IPA 준비 도구가 두 버전을 처리합니다. 코드 지문이 다르거나 암호화 또는 이미 패치된 파일은 중단합니다.

## 이번 실기에서 확인한 항목

- 기존 로그인, 데이터 컨테이너와 트윅 설정 유지.
- 세 차례 앱 복귀 후 채팅 탭 선택, 친구에서 채팅으로 바로 이동.
- 카카오 내부 iPad 판정 유지와 UIKit의 iPhone 판정. 기본 영문 QWERTY, 123 배열과 숫자 입력.
- 숏폼 숨김, 오픈채팅 자동 선택과 하단 탭 반복 선택.
- 설정 하단 메뉴, 257개 국가 목록, 가나 화면 적용 시 전화 탭 하나만 표시. 시험 후 계정 기본값 복원.
- 기존 삭제 텍스트 2개의 원문과 각각 하나의 빨간 표시. 12회 테이블 재구성에서 삭제 표시 중복이나 일반 메시지 오표시 없음.
- 원래 메시지 메뉴의 메시지 도구, 선택한 메시지 정보, 읽음 목록. 읽음 2명과 안 읽음 0명을 표시했고, 로컬에 이름이 없는 참여자 1명은 이름을 추정하지 않았습니다.
- 프로필 원본 필드의 710 x 842 사진을 재압축 없이 사진 앱에 저장. 사진 라이브러리 저장 완료 콜백 확인.
- 실제 네이티브 계산 함수에서 안 읽은 수 98, 99, 100, 350과 보조 기기 메시지 정책 확인.

로컬 회귀 시험 188건과 실제 실행 파일 비교 21건을 통과했습니다. 26.7.3의 준비 도구 출력은 기존 3.0.2와 바이트 단위로 같습니다. 버전별 세부 근거는 [validation.json](validation.json)과 [이전 검증 기록](validation-3.0.2.json)에 분리했습니다.

## 검증의 한계

미러링이 외부 키보드로 동작하므로 시험용 코드로 기본 화면 키보드를 표시했습니다. 기본 한국어 키보드와 미러링을 끈 물리 입력은 확인하지 않았습니다. 메시지 메뉴는 실제 기기에서 네이티브 제스처 콜백을 호출한 시험입니다.

이번 업데이트에서는 새 메시지를 보내거나 수정, 삭제, 반응하지 않았습니다. 이전 버전의 전송, 수정, 촬영 정보 제거 및 MP4 영상 시험 결과를 26.8.0의 새 시험으로 표시하지 않습니다. HLS 영상, 모든 광고 위치와 국가, 상대 기기의 입력 표시, 탈옥 실기 및 직접 SideStore 설치는 확인 범위 밖입니다.

배포물에는 트윅, 준비 도구와 문서만 포함하며 카카오톡 IPA, 대화, 개인 사진과 계정 정보는 포함하지 않습니다.
