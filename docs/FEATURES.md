# Ginppai 기능과 검증 범위

3.0.0은 KakaoTalk 26.7.3 / iOS 26.1 / SideStore + LiveContainer에서 확인한 정식 배포본입니다. 정식판 표시는 아래 미확인 환경까지 보장한다는 의미가 아닙니다. 기존 공개 안정판 기록은 validation-2.3.2.json에 별도로 남겼습니다.

| 기능 | 확인한 결과 | 남은 범위 |
|---|---|---|
| 화면 정리와 국가 선택 | 기존 광고 및 탭 기능 유지, 한국과 일본 화면 전환, 게임 탭 숨김과 복원 | 모든 국가와 광고 위치 |
| 특별한 친구 숨김 | 광고 숨김을 켜면 해당 프로모션 섹션을 제외하고 업데이트 프로필, 생일 친구, 즐겨찾기와 일반 친구 유지 | 모든 지역의 다른 광고 위치 |
| 친구 목록만 보기 | 옵션 끄기와 켜기, 소식 선택 상태에서 재실행, 하단 탭 반복 선택 후 친구 목록 확인 | 다른 iOS 버전 |
| 더보기 영역 선택 | 카카오나우와 날씨 숨김 및 복원, 서비스 아이콘 숨김, 광고의 큰 빈 공간 제거 | 페이와 세로형 서비스의 실제 노출 화면 및 다른 지역 배치 |
| 원본 미디어 저장 | 이전 안정판에서 프로필 원본 사진과 MP4 저장 및 재생 확인 | 실제 HLS 프로필 영상 |
| 촬영 정보 제거 | GPS, EXIF, IPTC가 있는 합성 사진을 원본 품질로 전송하고 서버 결과와 처리 파일 일치 확인 | 모든 업로드 경로. 미지원 형식은 원본 전송 |
| 메시지 정보와 읽음 목록 | 기본 메뉴 첫 행의 메시지 도구 버튼, 정확한 선택 메시지의 정보와 읽음 목록 진입, 기본 삭제 항목 접근 확인 | 직접 손가락 제스처와 긴 대화의 재사용 시험 |
| 메시지 보관함 | 실제 수정 전후 기록, 재실행 보존, 첨부 정보, 이전 원문 검색 및 빈 결과 안내 확인 | 모든 수신 경로 |
| 삭제 원문 표시 | 받은 메시지 2개와 보낸 메시지 1개의 실제 삭제 후 원문 및 빨간 표시, 연속 메시지 각각의 표시, 끄기와 재실행, 12회 화면 재구성과 일반 메시지의 오표시 없음, 삭제 말풍선 두 번 누르기 차단 확인 | 원문 미보관, 사진과 영상 복원은 미지원. 긴 대화의 스크롤 재사용과 직접 손가락 밀기 시험은 남음 |
| 안 읽은 수 확장 | 실제 iPhone 계산 함수가 100명 및 350명 반환 | 실제 대규모 대화 화면 |
| 입력 중 표시 숨김 | 입력 중 차단 경로 실행 확인 | 상대 기기 표시 관찰 |
| 텍스트 서식 전송 | 새 메시지 굵은 글씨 확인 | 새 전송만 지원. 수정하면 서식이 풀림 |
| 공유 카드 전달과 외부 브라우저 | 정확한 iOS 판단 경로에 옵션 연결 | 다양한 카드와 링크의 전체 실행 결과 |
| 보조 기기 메시지 표시 | 모바일 조건만 바꾸고 잠금 및 연령 조건 유지 확인 | 실제 제한 메시지 화면 |
| 분석 전송 제한 | 오류 수집기 시작 차단과 사용 분석 차단 호출, 공유 분석 주소에 대한 로컬 204 응답 확인 | 모든 SDK 경로와 백그라운드 URLSession |

탈옥 기기와 SideStore 직접 설치의 전체 동작은 아직 시험하지 않았습니다. 실제 기기 확인은 SideStore와 LiveContainer를 사용하는 iOS 26.1에서 진행했습니다. JIT은 이 트윅 자체에 필요하지 않습니다.
