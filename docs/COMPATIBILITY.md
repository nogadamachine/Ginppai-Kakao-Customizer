# 검증 범위

3.0.0의 정식판 확인 환경은 KakaoTalk 26.7.3 / iOS 26.1 / SideStore + LiveContainer입니다. 모든 기능과 설치 환경을 검증한 것은 아닙니다. [기능별 검증 범위](FEATURES.md)를 확인하세요. 아래 2.3.2 기록은 과거 안정판에만 적용됩니다.

## 2.3.2 확인 사항

- iPhone 13 Pro, iOS 26.1, KakaoTalk 26.7.3, LiveContainer에서 공개용 2.3.2 실행.
- 배경사진 확대 화면에서 버튼 한 번으로 1920×2560 원본을 사진 앱에 저장. 저장 위치 선택 메뉴가 열리지 않음.
- 프로필 기록 화면의 세로 이동 중 버튼 위치 유지, 이동 후 1554×2176 사진 저장. 다른 기록을 열어 1967×2560 사진 저장. 모든 페이지 전환 제스처를 개별 검증한 것은 아님.
- 사진 앱 보관함에서 시험한 사진 3장이 실제로 추가된 것을 확인.
- 확대 화면을 닫으면 저장 버튼도 숨겨지는 것을 확인.
- 설치된 코드와 배포 DYLIB의 코드 영역이 동일하며 기존 설정과 iPad 트윅이 유지됨.
- 파일 내보내기 경로와 실패 시 파일 저장 선택을 제거.

## 이전 버전에서 확인한 환경

- iPhone 13 Pro, iOS 26.1, KakaoTalk 26.7.3, SideStore + LiveContainer.
- 기존 2.3.0에서 현재 사진 2377×2380, 이전 사진 1920×2560, 배경사진 1814×2419 원본 저장.
- 배경사진은 화면용 1111×1481 대신 원본을 사용하며 서버 파일과 내보낸 파일이 바이트까지 동일함을 확인.
- MP4 영상 1080×2356, 약 13.9초, 1,108,037바이트를 사진 앱과 파일에 저장. 서버 파일 동일성 및 사진 앱 재생 / 정보 확인.
- 선택 미디어 / 원본 URL / 영상과 정지사진 구분 / 서명 쿼리 보존 등 9개 검증.
- 일본 / 미국 / 독일 / 한국 화면에서 중복 통화 탭과 주요 탭 옵션을 확인. 전체 국가를 개별 검증하지는 않음.

2.3.1은 공개 명칭과 설치 도구 호환성을 더한 버전입니다. 위 2.3.0의 파일 앱 내보내기 기록은 과거 검증이며, 2.3.2부터 저장 대상은 사진 앱으로 통일했습니다. 현재 배포본의 검증 결과는 `validation.json`을 참고하세요.

## 아직 확인하지 않은 범위

- 탈옥 루트풀 / 루트리스 기기에서 실제 설치 후 실행. DEB 구조 / 아키텍처 / 필터 / 서명은 정적으로 검사합니다.
- SideStore에 직접 설치한 카카오톡의 로그인, 푸시 알림과 앱 전체 기능. IPA 준비 도구 결과는 정적으로 검사합니다.
- 실제 프로필의 HLS 스트리밍 다운로드. 최고 해상도 선택과 재압축 없는 내보내기를 구현했지만 실기 영상은 MP4로 검증했습니다.
- 카카오톡 26.7.3 이외 버전. 해당 버전이 아니면 초기화를 생략합니다.
- rootless와 다른 별도 경로 변환이 필요한 부트스트랩.

계정 상태와 서버에서 내려주는 화면은 다를 수 있습니다. 이 트윅은 계정 국가나 전화번호를 변경하거나 iOS를 탈옥하지 않습니다.
