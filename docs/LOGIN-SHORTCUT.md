# 카카오 로그인 단축어 안내

설정 → Ginppai → 사용 방식 → 카카오 로그인 단축어

배포 링크: https://www.icloud.com/shortcuts/800cb2bb124246459f6d2e82d0566074

## 단축어 추가

**카카오톡 로그인 연결 단축어 추가**

단축어 추가 화면을 엽니다. 내용을 확인한 뒤 ‘단축어 추가’를 눌러 주세요. 이 버튼만으로 자동 설치되지는 않습니다.

**추가 링크 복사**

추가 화면이 열리지 않으면 링크를 복사해 Safari 주소창에 붙여 넣으세요. 다른 사용자에게 이 배포 링크를 공유할 수도 있습니다.

## 왜 필요한가요?

**설치돼 있는데 미설치 안내가 뜰 때**

외부 앱의 ‘카카오톡으로 로그인’을 눌렀는데 브라우저가 열리고 카카오톡이 없다는 안내가 나오는 경우에 사용합니다. 직접 서명해 설치한 환경에서는 웹 주소와 앱을 연결하는 정보가 달라져 이런 현상이 생길 수 있습니다.

**로그인 주소를 앱 연결 주소로 변환**

이 단축어는 브라우저가 받은 카카오 로그인 주소를 카카오톡이 직접 열 수 있는 주소로 변환합니다. 현재 요청의 인증 정보를 유지해 카카오톡 로그인 화면으로 연결합니다. 이미 로그인이 잘 된다면 사용할 필요가 없습니다.

## 처음 한 번 적용하기

**1. 단축어 추가**

위의 추가 버튼을 누르고 단축어 앱에서 ‘카카오톡 로그인 연결’을 추가하세요. 단축어 앱이 없다면 먼저 App Store에서 설치하세요. Ginppai의 ‘적용 후 종료’나 카카오톡 재실행은 필요하지 않습니다.

**2. 공유 메뉴에서 찾기**

Safari나 사용 중인 브라우저의 공유 메뉴에서 ‘카카오톡 로그인 연결’을 찾으세요. 보이지 않으면 단축어 앱에서 해당 단축어의 세부사항을 열어 ‘공유 시트에서 보기’를 켜세요. 입력 유형에 Safari 웹페이지, URL, 텍스트가 포함되어 있는지도 확인하세요.

## 로그인할 때 사용하는 방법

**1. 원래 앱에서 로그인 시작**

로그인하려는 앱의 ‘카카오톡으로 로그인’을 누르세요. 설치되지 않았다는 안내가 나오는 브라우저 화면을 닫거나 원래 앱의 로그인을 취소하지 마세요.

**2. Safari에서는 페이지 공유**

주소창 옆이나 브라우저 메뉴의 공유 버튼을 누르고 ‘카카오톡 로그인 연결’을 선택하세요. 단축어가 현재 페이지의 URL을 가져오므로 주소를 따로 복사할 필요가 없습니다.

**다른 브라우저나 앱에서는 링크 공유**

현재 페이지 또는 로그인 링크의 공유 메뉴에서 ‘카카오톡 로그인 연결’을 선택하세요. 일반 URL이나 링크가 포함된 텍스트를 받으면 그 안의 주소를 추출합니다. 로그인 링크 하나만 공유하세요. 복사만 해서는 실행되지 않으며, 현재 배포본은 클립보드를 자동으로 읽지 않습니다.

**3. 카카오톡에서 로그인 완료**

처음 실행할 때 앱 열기나 웹페이지 접근에 대한 허용을 요청하면 내용을 확인하고 허용하세요. 카카오톡의 로그인·동의 화면을 완료한 뒤 원래 앱으로 돌아가 로그인됐는지 확인하세요. 로그인할 때마다 새로 열린 페이지나 링크에서 실행하세요.

## 잘 안될 때

**공유 메뉴에 단축어가 없어요**

공유 메뉴 아래쪽까지 내려 확인하세요. 그래도 없으면 단축어의 ‘공유 시트에서 보기’와 입력 유형을 확인하세요. 일부 앱은 링크를 공유하지 않을 수 있으니 로그인 페이지를 Safari에서 열어 공유해 보세요.

**잘못된 요청·SDK 오류가 떠요**

원래 앱에서 로그인을 다시 시작한 뒤 새 로그인 링크를 공유하세요. 단축어를 편집했다면 ‘접두사 제거 → URL 디코딩 한 번 → URL → URL 열기’ 순서와 변수 연결을 확인하세요. SDK 버전이나 인증 파라미터를 임의로 바꾸지 마세요.

**카카오톡은 열리지만 로그인이 안 끝나요**

원래 앱에서 요청이 취소됐거나 만료됐을 수 있습니다. 원래 앱에서 다시 로그인을 시작해 주세요. 완료 여부는 해당 앱의 로그인 처리에도 영향을 받습니다.

## 지원 범위와 기록

**공유 메뉴에서 직접 실행**

이 기능은 외부 앱의 로그인 버튼을 자동으로 가로채거나 iOS의 웹 연결 설정을 복구하지 않습니다. 브라우저가 열렸을 때 공유 메뉴에서 단축어를 실행해야 합니다. 브라우저와 앱의 공유 방식에 따라 동작이 달라질 수 있습니다.

**로그인 주소를 저장하지 않아요**

Ginppai의 이 안내 화면은 고정된 단축어 배포 링크만 열거나 복사합니다. 개인 로그인 주소나 클립보드를 읽지 않습니다. 현재 공유된 단축어는 받은 주소를 기기에서 변환해 카카오톡으로 전달합니다.

## 유지관리 시 검토할 점

이 화면은 제공된 iCloud 배포 링크를 열거나 복사합니다. 공유된 단축어 자체를 자동 설치하거나 외부 앱의 로그인 요청을 가로채지 않습니다.

현재 공유본은 Safari 웹페이지와 URL·텍스트 입력을 분기하고, 접두사 제거 → 디코딩 한 번 → 명시적 URL 구성 → 열기 순서로 동작합니다. 클립보드 자동 읽기나 별도 네트워크 조회 동작은 확인되지 않았습니다. Safari 유형 비교가 한국어 문자열이므로 다른 시스템 언어는 추가 검증해야 합니다. 빈 입력·임의 주소·여러 URL에 대한 단축어 내부 보호도 보완 대상입니다.

배포 링크는 기여자가 제공한 iCloud 단축어입니다. 유지관리자가 직접 관리하려면 단축어를 복제해 자체 링크를 발급하고 `kcLoginShortcutURL()`을 교체하는 방식을 권장합니다. 공유본은 앱 소스에 내장된 파일이 아니므로 이 소스 패치만으로 단축어의 향후 배포 상태까지 고정되지는 않습니다.

로컬 사용자에게서 URL 동작을 추가한 구성으로 로그인 성공을 확인받았습니다. 새 안내 화면과 모든 브라우저·언어·서명 환경은 실기 검증이 필요합니다.
