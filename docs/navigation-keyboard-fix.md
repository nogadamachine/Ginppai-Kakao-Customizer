# 3.0.2 탭 전환과 1.1.0 키보드 수정

## 원인과 변경

카카오톡 26.7.3은 UIKit의 selectedIndex 외에 자체 탭 선택 상태를 유지합니다. 이전 시작 화면 처리에서 selectedIndex만 바꾸면 다음 채팅 탭 선택이 무시될 수 있었습니다. 원래 버튼의 touch-down과 touch-up 처리로 전환하고, 시작 화면은 한 프로세스에서 한 번만 적용합니다. 사용자가 탭이나 대화방으로 이동한 뒤 대기 중인 시작 화면 전환이 덮어쓰지 않도록 검사합니다.

탭 다시 누르기는 touch-down 이전에 이미 선택된 탭인 경우에만 처리합니다. 다른 탭으로 이동하는 동작을 다시 누르기로 오해해 목록을 맨 위로 옮기지 않습니다.

iPad 트윅은 카카오톡 앱 번들 안의 코드가 호출할 때만 기기 종류와 모델 이름을 바꿉니다. 시스템 UI와 기본 키보드는 실제 기기 정보를 받습니다. 두 트윅은 각각 업데이트해야 합니다.

## 확인한 결과

- 기존 3.0.1에서 더보기, 채팅, 직접 친구 선택, 채팅 순서로 실제 오류를 재현했습니다. 마지막 채팅 선택은 무시됐고, 다른 탭을 거쳐야 채팅이 나타났습니다.
- 수정본에서 실제 네이티브 탭 버튼 처리와 화면 전환을 확인했습니다. 친구 목록은 이동 전후 스크롤 좌표가 같았습니다. 채팅은 원래 헤더 재배치로 좌표가 조정됐지만 맨 위로 이동하지 않았고, 다시 누를 때는 두 목록 모두 맨 위로 이동했습니다. 오픈채팅 탭은 다시 눌러도 숏폼으로 전환되지 않았습니다.
- 세 차례 백그라운드와 복귀 시험에서 채팅 선택이 유지됐으며 친구에서 채팅으로 한 번에 이동했습니다.
- iPad 트윅의 호출자 경계 13건을 ASan과 UBSan으로 검사했습니다.
- 카카오톡 내부의 기기 판정은 iPad, 실제 앱 창은 iPhone이었습니다.
- 기본 영문 키보드의 iPhone 배열, 123 전환과 숫자 입력을 확인했습니다. 미러링이 외부 키보드로 인식되므로 비공개 시험 코드로 화면 키보드를 표시했습니다. 물리 기기에서 미러링을 끈 상태의 손가락 입력과 기본 한국어 키보드는 별도 검증하지 않았습니다.
- 전체 기존 사용자 옵션, 한국 계정 기본 화면과 데이터 컨테이너를 유지했습니다. 시험 코드와 시험용 보조 터치 설정은 제거하거나 원복했습니다.

확인 환경은 iPhone 13 Pro, iOS 26.1, KakaoTalk 26.7.3, LiveContainer 3.8.0입니다. 카카오톡 26.8.0, 탈옥 실기와 직접 SideStore 설치는 이번 검증에 포함되지 않습니다.
