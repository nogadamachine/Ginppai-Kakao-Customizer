# 이번 기여의 검증 범위

기준: `nogadamachine/Ginppai-Kakao-Customizer` main, `ad63af8ab9391e2862409fac4b078d7c644395d7`.

이번 검토 소스는 로컬에서 사용한 전체 수정본에서 이모티콘 플러스 및 새 전송·패킷·첨부 구조 진단, JSON 저장 스위치를 제외한 별도 사본입니다. 원본의 상태 보고와 메시지 보관 기능은 유지합니다. 원본 `docs/validation.json`은 기존 릴리스의 기록이며, 이번 변경의 실기 검증으로 해석하지 않습니다. 버전·라이선스·작성자 정보도 원본을 유지합니다.

## 로컬 검사

2026-10-16에 이 분리된 소스 자체로 `python3 test.py`, `python3 build.py`를 실행해 통과했습니다.

- 원본 도구 검사 16개, SDK 광고 Native 준비 검사 7개
- 원본 미디어 검사 9개, 메시지 정책 검사 119개(이번 친구 광고 섹션 정책 8개 포함)
- 실제 Swift enum·KCMessageBridge·Objective-C 스냅샷 변경 통합 검사 14개
- 사진 개인정보 검사 30개, 더보기 렌더링 검사 22개
- 추가 광고 Objective-C ABI·실패 콜백 검사
- 광고 높이·셀 재사용·일반 행 보존·제약 범위·약한 참조·갱신 억제 테스트
- iOS arm64 / 최소 iOS 17 빌드

새 광고 레이아웃 테스트는 Foundation UI 대역을 사용하며, 실제 UIKit 화면 검증과 구분합니다.

## 사용자의 기기 보고

- 추가 광고 차단은 동작한다는 보고를 받았습니다.
- 단축어는 URL 디코딩 이후 명시적 URL 동작을 거쳐 열 때 로그인 성공을 확인받았습니다.
- 첫 광고 여백 수정 이후에도 친구 목록의 내 프로필 아래 여백이 남는다는 보고가 있었습니다.
- 이후 친구 목록 `bizboard` 섹션을 제외하는 최신 변경은 아직 실기 확인을 받지 못했습니다.
- 새 단축어 안내 화면, 모든 브라우저·언어 및 탈옥·LiveContainer 환경은 별도 검증이 필요합니다.

## 유지관리자 검토 항목

SDK Native 준비는 정확한 26.8.0 / 2026.9.14.1 바이너리에 한정됩니다. dylib만 설치하면 Thread/Focus용 사전 준비가 자동으로 생기지 않습니다. 절대 크기를 쓰는 미확인 레이아웃의 여백까지 해결한 것으로 볼 수 없습니다.

단축어 링크는 기여자가 제공한 iCloud 공유본입니다. 유지관리자 소유의 링크로 교체할지 결정해야 합니다. 공유본의 한국어 유형 비교, 빈 입력·여러 URL·임의 주소 보호는 별도 보완 대상입니다.
